Central limit theorem from a linear regression angle

We simulate Y = β₀ + β₁X + ε where the error is a sum of k independent, identically distributed small shocks (uniform on [−1, 1]), scaled so total variance stays ~1. As k grows, the error distribution becomes nearly normal (CLT), so assuming normal residuals in regression is natural when many unrelated influences add up.

Each shock is Uniform(−1, 1) with variance ⅓. We set ε = (η₁ + … + ηk) / √(k/3) so Var(ε) ≈ 1 for every k — only the shape of the error changes as you add more terms. Studentized residuals adjust for leverage so the comparison to a standard normal is fair across n.
